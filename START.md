# Getting Started

## Human Before AI — IndependentLogicLab

This guide explains how to prepare, configure, and run our independent research software.

## 1. System Requirements

- Windows, macOS, or Linux
- Python 3.11 or newer
- Internet connection
- Free GitHub account
- Authorized GPTZero API access for automated detector testing

## 2. Software Requirements

- Python
- Python package manager (pip)
- Git (optional)
- Text editor

All required software must be freely available.

## 3. Installation

Download or clone the Human-Before-AI repository.

Open a terminal inside the downloaded repository folder.

Check your Python installation:

`python --version`

Additional installation instructions will be provided as research modules are developed.

## 4. API Configuration

GPTZero API credentials must be stored locally and must never be uploaded to GitHub.

The planned environment variable is:

`GPTZERO_API_KEY`

Automated testing must remain within authorized API usage limits and available free research credits.

## 5. Research Workflow

1. Locate authentic historical publications.
2. Verify authorship and publication dates.
3. Record original source information.
4. Extract consecutive, unmodified passages.
5. Generate unique sample identifiers.
6. Record text integrity hashes.
7. Submit samples for authorized detection testing.
8. Record detection results.
9. Analyze statistical patterns.
10. Independently verify potential false positives.
11. Prepare research reports and qualifying bounty submissions.

## 6. Research Safeguards

- No upfront financial investment.
- No unauthorized API requests.
- No fabricated research results.
- No artificial manipulation of historical passages.
- No publication of private credentials.
- No intentional charges or paid API usage.
- Preserve original source references.
