# Original Historical Publications

IndependentLogicLab — Human Before AI

This directory contains original public-domain historical publications used as primary research evidence.

## Preservation Standards

- Preserve original downloaded files without modification.
- Identify documents using their assigned source IDs.
- Record SHA-256 fingerprints.
- Maintain original publication dates and source URLs.
- Verify public-domain status before inclusion.
- Never use AI to rewrite historical content.
- Keep original documents separate from extracted text and research samples.

## Naming Convention

Original documents must use their assigned source identifier.

Examples:

- AGR-0001.pdf
- SCI-0002.pdf
- MAT-0001.pdf
