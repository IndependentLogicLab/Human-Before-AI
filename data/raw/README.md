# Historical Source Documents

This directory stores authentic historical publications used in the Human Before AI research project.

## Document Requirements

- Published before 1950.
- Verifiable human authorship.
- Public-domain material.
- UTF-8 plain-text format.
- Original wording preserved.
- Minimum of 750 words.
- Corresponding entry in `sources/catalog.csv`.

## Approved Source Repositories

- Project Gutenberg
- Wikisource
- Internet Archive
- Library of Congress
- Project Gutenberg Australia

## Naming Convention

Documents will use the following naming convention:

- SCI-0001.txt — Scientific publications
- MAT-0001.txt — Mathematics textbooks
- GOV-0001.txt — Government publications
- AGR-0001.txt — Agricultural manuals
- ENG-0001.txt — Engineering manuals
- MED-0001.txt — Historical medical publications
- LEG-0001.txt — Legal publications
- EDU-0001.txt — Educational textbooks
- PHI-0001.txt — Philosophical publications
- LIT-0001.txt — General literature

Each document must be verified before being used in detection experiments.
